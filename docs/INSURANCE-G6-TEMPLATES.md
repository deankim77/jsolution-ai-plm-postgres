# 손해보험 G1~G6 템플릿

- 신규 보험상품 개발 프로젝트: INS-PRODUCT-G6
- 손해보험 업무 개선 프로젝트: INS-IMPROVEMENT-G6
- 각 템플릿: 1레벨 Gate 6개, 2레벨 실행 업무 18개·승인 업무 6개, 총 30행.
- 담당 역할, 예시 영업일 기간, 선행 업무, 필수 문서, 완료·Gate 승인 조건 포함.
- 날짜·실적·실제 사용자 배정 없는 재사용 템플릿. 프로젝트 생성은 별도입니다.
- 특정 보험사의 실제 내부 절차나 규정 준수 완료를 의미하지 않는 데모 표준안입니다.

## 등록

서버에서 최신 소스를 받은 후 프로젝트 폴더에서 실행합니다.

```powershell
node scripts/seed-insurance-templates.mjs
node scripts/seed-insurance-templates.mjs --apply
```

실행 중인 서버나 브라우저 로그인은 필요하지 않습니다. 서버를 켜둬도 됩니다.
기존 DB 마이그레이션과 동일하게 DATABASE_URL 환경변수 또는 프로젝트 .env를 읽습니다.
Drizzle/PostgreSQL 트랜잭션으로 두 템플릿을 등록하며, 하나라도 실패하면 함께 취소합니다.
활성 회사가 하나면 자동 선택하고, 여러 회사면 PMS_COMPANY_ID로 대상을 지정해야 합니다.
대상 회사의 활성 관리자 계정 중 하나를 생성자로 기록합니다. PMS_SEED_USER_ID로 특정 관리자를 지정할 수 있습니다.
같은 코드가 이미 있으면 그대로 유지합니다. 기존 제조 템플릿과 프로젝트는 수정하지 않습니다.
등록 후 템플릿 목록을 새로고침하고, 새 프로젝트 생성 시 선택합니다.
