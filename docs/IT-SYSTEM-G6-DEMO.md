# IT 시스템 개발 표준 템플릿 및 프로젝트

`node scripts/seed-it-system-demo.mjs --apply` 한 번으로 템플릿과 프로젝트, 프로젝트 유형, 실적, Gate 승인, Baseline, 산출물 원본과 리비전을 등록합니다. 서버 실행이나 브라우저 로그인이 필요하지 않습니다. 기존 `.env`의 `DATABASE_URL`과 Storage Adapter 설정을 사용합니다. 실제 서버의 프로젝트 폴더에서 실행하세요.

```powershell
cd C:\Projects\jsolution-ai-plm-postgres
git pull origin main
node scripts/seed-it-system-demo.mjs --apply
```

기준일은 한국 날짜의 실행일이며 시작일은 기준일의 7일 전입니다. 회사 기본 업무 캘린더의 근무요일과 휴무일을 반영합니다. 기준일을 고정하려면 실행 전에 `$env:IT_DEMO_DATE = "2026-10-20"`을 지정하세요. 환경변수를 해제하려면 `Remove-Item Env:IT_DEMO_DATE -ErrorAction SilentlyContinue`를 실행하세요.

- 템플릿: **IT 시스템 개발 표준 프로젝트** (`IT-SYSTEM-G6`, v1.0)
- 프로젝트: **보험업무 통합관리 시스템 구축** (`IT-INS-SYSTEM`)
- PM: 해당 회사의 활성 `dean@jsolution.io` 또는 기존 `dean@jjjsolution.com` 계정
- 거래처: 기존 농협손해보험 거래처를 우선 사용
- 프로젝트 유형: **IT 시스템 개발**
- 구조: G1~G6, 2레벨, 단계별 실행 업무 3개와 Gate 승인 1개, 상위 단계 포함 30행

| 단계 | 내용 |
| --- | --- |
| G1 | 착수 및 계획 |
| G2 | 요구사항 분석 |
| G3 | 시스템 설계 |
| G4 | 개발 및 단위검증 |
| G5 | 통합검증 및 인수 |
| G6 | 오픈 및 안정화 |

2026-10-20 기준으로는 10월 13일 착수, G1 통과, G2 요구사항 분석 진행 중입니다. 완료 업무 5개, 진행 업무 1개, 실적과 협업 요청 1건을 등록합니다. 미래 업무에는 계획 산출물 항목만 만들며 완료 실적이나 문서 파일을 미리 등록하지 않습니다.

Gate 태스크는 G2-REVIEW의 선행을 G1-REVIEW, G3-REVIEW의 선행을 G2-REVIEW처럼 직접 연결합니다. 각 단계 첫 실행 업무도 이전 Gate가 선행이며, 단계 내 실행 업무 세 개는 순차 연결합니다. Gate 승인일은 해당 단계의 실행 업무 종료 이후로 배치합니다. 현재 단일 선행 필드 구조이므로 Gate가 단계 내 마지막 실행 업무까지 두 개의 선행을 동시에 갖지는 않습니다. 단계 업무를 변경한 경우 승인 예정일도 함께 검토해야 합니다. 간트의 실제 CPM 계산으로 G1~G6 Gate의 여유 일정이 모두 0인 것을 테스트합니다.

산출물 24종의 등록 계획 중 2026-10-20 기준 6종을 실제 DOCX와 텍스트 미리보기로 저장합니다. 착수계획서, 업무 범위 정의서, 사용자 요구사항 정의서는 각각 Rev.01~03이 존재하며 추가 조항이 누적됩니다. 총 12개 리비전입니다. 문서의 프로젝트명과 파일 제목에는 데모라는 표기를 넣지 않습니다. 내부 프로젝트 설명에는 실제 고객 정보가 없는 예시 자료임을 기록합니다.

재실행은 프로젝트 코드로 확인하여 기존 프로젝트, 사용자가 입력한 실적, 문서와 리비전을 유지합니다. 기존 IT 템플릿의 WBS가 달라져 있으면 덮어쓰지 않고 중단합니다. DB 입력은 트랜잭션으로 묶이며 실패 시 새 Storage 파일을 정리합니다. 보험 상품 및 업무 개선 프로젝트와 사용자 정보는 변경하지 않습니다. 여러 활성 회사가 있으면 `PMS_COMPANY_ID`로 대상을 지정해야 합니다.

DB 변경 없이 구조만 확인하려면 옵션 없이 실행하세요. `--documents-only`는 DB를 변경하지 않고 `.demo-generated/it-system-g6`에 기본 주중 캘린더 기준 문서와 목록을 생성합니다. 실제 등록은 회사 캘린더로 다시 계산합니다.
